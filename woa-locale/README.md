# WOA locale (niente download)

Launcher **indipendente** da `offline-kit`. Non è un nuovo server HITMAN e non emula Steam/Epic/Xbox.

Avvia **solo** Peacock che hai già sul disco:

`C:\Games\HITMAN - World of Assassination\Peacock`

- Nessun GitHub, nessuna `ScaricaRelease`, nessun zip Peacock.
- Se quella cartella manca, si ferma. Non scarica nulla.
- I progressi stanno in `...\Peacock\userdata\users\dbb3dd5d-....json`

## Ogni giorno

1. Chiudi HITMAN, Patcher, ogni finestra Peacock Server.
2. Tasto destro su **`Gioca.cmd`** → amministratore.
3. Hub → Planning → Start. Non Continua/Carica.
4. Esci dal gioco, aspetta 10 secondi, premi Q.

## Prova senza internet (ora, a casa)

1. Spegni Wi-Fi / cavo.
2. **`ProvaOffline.cmd`** (admin). Se vede ancora rete, esce.
3. Hub → Planning → Start.
4. Incolla se: Peacock parte, patcher `127.0.0.1`, hub con mappe oppure «richiedi accesso».
